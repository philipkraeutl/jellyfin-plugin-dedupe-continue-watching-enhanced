Continue Watching Deduplicator Enhanced

Removes duplicate episodes from the Continue Watching row. Each series will appear once, represented by the most recently played episode.

When disabled, the plugin acts as a no-op (no API responses are modified).
Deduplicate the Up Next row and hide series already shown in Continue Watching. Disabled by default.
Only useful if you have multiple versions of the same movie file.
Default: 1 (only the most recent episode per series). Set higher to keep multiple episodes per series in Continue Watching.
